# 조작과 도구

화면 문구는 한국어입니다. 아래 키 이름은 브라우저 `event.code` / `event.key`와 같습니다. 적힌 것만 코드가 받습니다.

입력란·선택 상자·텍스트 영역에 포커스가 있으면 편집 단축키와 플레이 키는 동작하지 않습니다. 플레이 키는 **게임 캔버스가 포커스**일 때만 잡힙니다.

## 플레이

`src/input.ts` 바인딩입니다. 반대 방향은 서로 상쇄됩니다. 점프·발사 키의 키 리피트는 무시됩니다.

| 동작 | 키 |
| --- | --- |
| 왼쪽 | `ArrowLeft`, `KeyA` |
| 오른쪽 | `ArrowRight`, `KeyD` |
| 위 (덩굴·토관) | `ArrowUp` |
| 아래 (웅크리기·토관) | `ArrowDown`, `KeyS` |
| 점프 / 헤엄 | `Space`, `KeyZ` |
| 달리기 / 불꽃 | `ShiftLeft`, `ShiftRight`, `KeyX` |
| 일시정지 | `Escape` |

`KeyW`는 묶여 있지 않습니다. WASD처럼 보이지만 위는 화살표만입니다.

오버레이 안내: `이동 ← → 또는 A D · 점프 Space 또는 Z · 달리기 Shift 또는 X · 일시정지 Esc`.

버튼 (`src/ui/editor-gallery.ts`):

| `data-testid` | 라벨 | 동작 |
| --- | --- | --- |
| `play-start` | ▶ 플레이 | 코스 시작 위치에서 시험. 목표가 없으면 막힙니다. |
| `play-cursor` | 커서에서 테스트 | 마지막으로 가리킨 칸의 바닥 중앙에서 시험. 칸 위에 커서가 없으면 오류입니다. |
| `play-sandbox` | 목표 없이 테스트 | 목표 검사 없이 시험합니다. |
| `pause` | 일시정지 | 플레이 중에만 보입니다. |
| `resume` | 재개 | 일시정지 중에만 보입니다. **Esc는 재개가 아닙니다.** 창이 숨겨져 있으면 재개하지 않습니다. |
| `retry` | 다시 도전 | 사망 중에만 보입니다. |
| `restart-course` | 처음부터 다시 | 런타임 카운터를 초기 스냅샷으로 돌립니다. |
| `return-editor` | 편집으로 돌아가기 | 플레이 변경을 버리고 선택·카메라를 복원합니다. |
| `audio-mute` | 음소거 / 소리 켜기 | 이번 세션 음소거. 작업실에는 음량 슬라이더가 없습니다. |

탭이 숨거나 창이 포커스를 잃으면 일시정지하고 누른 키를 비웁니다. 다시 시작하려면 **재개**를 눌러야 합니다. 일시정지 중에 누른 키는 재개 입력으로 이어지지 않습니다.

## 편집 도구

도구를 고르기 전에는 왼쪽 클릭이 칠하지 않습니다. `tool` 초기값은 없음입니다.

| 버튼 | `data-testid` | 동작 |
| --- | --- | --- |
| 그리기 | `tool-paint` | 타일이면 드래그한 칸을 한 명령으로 칠합니다. 배치 가능 오브젝트면 클릭 한 번에 16픽셀 격자에 놓습니다. |
| 지우기 | `tool-erase` | 드래그한 칸의 타일을 지웁니다. |
| 채우기 | `tool-fill` | 드래그 사각형. 미리보기는 잘릴 수 있고, 커밋은 영역 밖 사각형을 거절합니다. |
| 선택 | `tool-select` | 마퀴로 오브젝트를 고르고, 이미 고른 것을 다시 누르면 이동합니다. |
| 실행 취소 | `undo` | 스택이 비면 비활성. 한도는 200명령 (`HISTORY_CAP`). |
| 다시 실행 | `redo` | 스택이 비면 비활성. 빈 동작·취소된 제스처는 다시 실행을 지우지 않습니다. |
| 시작 위치 | `viewport-home` | 현재 영역의 시작(없으면 `(40, 208)`)으로 카메라를 옮깁니다. |
| 격자 | `viewport-grid` | 16픽셀 격자 표시. |
| 1× 2× 4× 8× | `zoom-1` … `zoom-8` | `EDITOR_ZOOMS`. |

팔레트 분류: 지형, 아이템, 장치, 목표, 적, 발사체. 라벨은 `CATALOG_CATEGORIES`와 `*.label`입니다. `placeable: false`인 항목은 `· 자동 생성`으로 보이고 배치되지 않습니다.

**뻐끔플라워**는 그리기 클릭으로 놓지 않습니다. 같은 영역 토관 `pipeId`가 필요하고, 입구 좌표는 토관에서 나옵니다.

제스처:

- 왼쪽 드래그: 활성 도구의 칠·지우기·채우기, 또는 선택 마퀴/이동.
- 가운데 버튼 드래그, 또는 **스페이스를 누른 채** 왼쪽 드래그: 화면 이동. 스페이스를 떼면 진행 중 제스처도 취소합니다.
- 휠 (Ctrl/Meta 없이): 포인터 기준으로 확대/축소.
- 드래그 중 Esc: 그 제스처를 취소하고 문서를 바꾸지 않습니다.

## 편집 키보드

캔버스가 포커스이고 입력란이 아닐 때 (`src/ui/editor.ts`):

| 키 | 동작 |
| --- | --- |
| `Ctrl+Z` / `Meta+Z` | 실행 취소 |
| `Ctrl+Y` / `Shift+Ctrl+Z` (Meta 동일) | 다시 실행 |
| `Ctrl+C` | 앱 내부 복사. 운영체제 클립보드가 아닙니다. |
| `Ctrl+X` | 잘라내기 |
| `Ctrl+V` | 붙여넣기. 포인터가 있으면 그 격자로, 없으면 `(16, 0)` 칸만큼 밉니다. ID는 새로 발급합니다. |
| `Ctrl+D` | 복제 |
| `Delete` / `Backspace` | 선택 삭제 (입력란이 아닐 때) |
| `Escape` | 제스처 취소, 아니면 선택·배치 모드 해제 |
| `Space` | 팬 준비 |
| `1` `2` `4` `8` | 확대 (`event.key`) |
| 화살표 | 카메라 32CSS픽셀 팬 |
| `Home` | 시작 위치로 화면 이동 |

제목 칸은 Enter로 적용합니다. 입력 중 값은 초안입니다.

## 작업실 머리글

| 라벨 | 동작 |
| --- | --- |
| 보관함 | 보관함으로 돌아갑니다. |
| 내보내기 | 지금 메모리의 유효한 문서를 JSON으로 내려받습니다. 디스크에 쓰였는지는 확인하지 않고, 더티 표시도 지우지 않습니다. |
| 가져오기 | `.json` / `application/json` / `.smb1.json`. 실패해도 열린 문서는 유지됩니다. |
| 코스 제목 | 앞뒤 공백 없이 1–80자. |

저장 줄 (`save-status`): `저장됨`, `편집됨`, `저장 실패`(다시 시도), `로컬 저장 불가`. IndexedDB를 못 열면 메모리에서 편집은 되지만 가져오기는 보관함에 넣지 못합니다.

## 속성 패널

대부분 기본값 미리보기입니다. 실제로 커밋하는 컨트롤:

- 제한 시간 (초), 힌트 `0=무제한`. 유효 값은 0 또는 30–999.
- 시작 위치 / 깃발 목표 / 성 목표: 누른 뒤 캔버스를 클릭해 둡니다. 시작은 칸 바닥 중앙(`x = 칸*16+8`).
- 영역 이름, 테마 (지상·지하·수중·성), 너비 32–4096, 높이 15–128, 크기 적용 / 축소 확인.
- 영역 추가, 영역 삭제(마지막 영역은 거부, 시작 영역이면 다른 시작을 먼저 고름).
- 토관 배치, 서로 연결, 선택한 토관 삭제, 워프 존 배치, 워프 라벨 적용.

**아직 없거나 비활성인 것**

- 발판 **길이 초안** 숫자는 미리보기 검증만 하고 문서에 쓰지 않습니다.
- 선택 오브젝트의 색·입구·다리 폭 등은 이 패널에서 고치지 못합니다. 기본값으로 놓인 뒤 JSON으로만 바꿀 수 있습니다.
- **토관 배치** 버튼은 카탈로그 기본 높이 3이 아니라 높이 2로 둡니다.
- 본편 작업실에 음량·모션 감소 UI는 없습니다. `src/ui/settings.ts` 기본 음량 0.7은 코드 기본값입니다.
- 보관함 화면에 가져오기·내장 샘플 목록이 없습니다.
